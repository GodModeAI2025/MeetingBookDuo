# MeetingBook

Native notebook workspace for iOS and iPadOS 26 and later, built with SwiftUI, UIKit and PencilKit.

Open `MeetingBook.xcodeproj` in Xcode, select the `MeetingBook` scheme and an iPhone or iPad simulator. Swift Package Manager resolves the pinned dependencies. Real-device distribution requires suitable Apple signing credentials and app identifiers.

The app includes paper templates, typed handwriting, Pencil input, local font creation, export and optional iCloud synchronization. Release and device verification are tracked separately from source availability.

Bundled font licenses are in `MeetingBook/Resources`. ZIPFoundation's license is included with the app resources.
